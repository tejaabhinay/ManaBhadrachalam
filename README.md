# Mana Bhadrachalam 

A comprehensive digital portal dedicated to the tourism and cultural heritage of Bhadrachalam. This isn't just a app; it’s a localized search engine for the town.

###  Key Features
* **Dynamic Information Routing:** Built using EJS to serve dynamic content pages for different landmarks, reducing the need for hundreds of static HTML files.
* **SEO & Accessibility:** Optimized meta tags and semantic HTML to ensure the site ranks well for local travel queries.
* **Interactive UI:** Custom CSS animations to guide the user through the town’s history and map locations.
* **Admin Control:** Integrated a backend route to display bus schedules.

### Tech Stack
* **Backend:** Node.js & Express.js
* **Frontend:** React Native 
* **Styling:** Custom CSS3 
* **Deployment:** Expo Go & Render

> **Key Learning:** This project taught me the importance of SEO and how server-side rendering (SSR) via EJS can significantly improve load times for users on 3G/4G networks.
